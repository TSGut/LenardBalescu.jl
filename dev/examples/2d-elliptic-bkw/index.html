2D Elliptical BKW walkthrough

This page is a walkthrough of examples/2D_run_lenardbalescu_demo_elliptical_bkw.jl. It explains what the script does, in order, and how to modify it.

What this example is

  • Operator: 2D Lenard–Balescu (use_lenard_balescu=true)
  • Symmetry mode: non-radial / elliptical BKW (radial_symmetry=false by default in the script)
  • Initial condition: stratified elliptical BKW (initialize_particles_stratified_BKW_elliptical)
  • Entry point function: run_lenardbalescu_animation_elliptical_bkw

The script calls the convenience wrapper at the bottom, so running the file executes the demo immediately.

Step 1 — Run it as provided

From the repository root:

julia --project -e 'include("examples/2D_run_lenardbalescu_demo_elliptical_bkw.jl")'

This runs the convenience call at the end (the file uses longer defaults suitable for producing full output).

Step 2 — Understand the flow inside the function

run_lenardbalescu_animation_elliptical_bkw does the following:

  1. Creates RNG and parameters (rng = MersenneTwister(seed), par = SetParam()).
  2. Configures 2D discretization and timing (par.dim = 2, par.Nv, par.Npc, par.dt, par.ntot, par.T).
  3. Sets Lenard–Balescu k-space controls (par.k_perp_order, par.k_perp_max, par.k_parallel_width, par.k_parallel_order) and calls update_kernel_params!(par).
  4. Optionally builds an initial f_grid and radial diagnostics for plotting when plot_grid=true.
  5. Prepares output folders and a frames array if PNGs/animation are requested.
  6. Defines a visualization_callback(k, vstack, wg, par, Vgrid, Vc) which:
    • computes conserved quantities and appends to mass_hist, energy_hist, momentum_hist;
    • reconstructs f_grid = f_recon(...);
    • when plot_grid=true it builds a four-panel diagnostic: particle scatter, density heatmap, radial binned f(r), and radial derivative plots;
    • saves per-step PNG frames and collects them for a GIF.
  7. Calls run_simulation(...) with:
    • use_lenard_balescu=true
    • init_particles=(N, dV, Vgrid, par, rng) -> initialize_particles_stratified_BKW_elliptical(...)
    • visualization callback attached and trackconserved=true.
  8. After the run, assembles conserved/error plots, saves PNG summaries, and — if requested — writes a GIF from saved frames.

Step 3 — Run a quicker variant interactively

For iteration and development, run with fewer timesteps and smaller kernels:

using LenardBalescu
include("examples/2D_run_lenardbalescu_demo_elliptical_bkw.jl")

run_lenardbalescu_animation_elliptical_bkw(
    ntot=60,
    seed=1,
    batchsize=0,
    stretch=1.5,
    save_pngs=false,
    plot_grid=true
)

This reduces walltime while keeping the visualization pipeline intact.

Step 4 — What to modify (and what each knob changes)

Initial condition / geometry

  • stretch: stretches the BKW distribution into an ellipse — increase to accentuate anisotropy.
  • The initializer is provided inline via the init_particles lambda that calls initialize_particles_stratified_BKW_elliptical.

Runtime and cost

  • ntot: number of timesteps (dominant runtime factor).
  • batchsize: RBM batching size; set to 0 for full pairwise collision (slower but exact), or to a positive integer to enable RBM batching and reduce cost.
  • par.Nv, par.Npc: change particle/discretization resolution — increasing increases accuracy and cost.

Lenard–Balescu fidelity controls

  • par.k_perp_order, par.k_perp_max, par.k_parallel_width, par.k_parallel_order control quadrature and k-space coverage. Higher values improve accuracy but increase kernel-precompute and collision cost.

Output and visualization

  • save_pngs: toggle per-step PNG saving (used to create the GIF).
  • plot_grid: toggle the diagnostic panel construction.
  • out_gif, out_dir: file locations for GIF and frames.

Practical notes

  • The convenience call at the bottom auto-runs a long example. Comment it out for library-style usage and call the function yourself with smaller parameters when developing.
  • The example uses initialize_particles_stratified_BKW_elliptical which seeds particles with stratified sampling — change to another initializer for different starting distributions.
  • When batchsize==0 the example runs the full pairwise collision operator (highest fidelity); try modest batchsize values to trade accuracy for speed during exploration.

Relevant files

  • Example script: examples/2D_run_lenardbalescu_demo_elliptical_bkw.jl
  • Initializer: initialize_particles_stratified_BKW_elliptical (see src/init_particles.jl)
  • Simulation core: run_simulation (see src/simulate.jl)
