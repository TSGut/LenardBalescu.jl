3D Torus walkthrough

This page is a walkthrough of examples/3D_run_lenardbalescu_demo_torus.jl. It explains what the script does, in order, and how to modify it.

What this example is

  • Operator: 3D Lenard–Balescu (use_lenard_balescu=true)
  • Symmetry mode: non-radial (radial_symmetry=false)
  • Initial condition: torus in velocity space (initialize_particles_torus_3d)
  • Entry point function: run_lenardbalescu_demo_3d_torus_nonradial

At the bottom of the script, this function is called directly, so running the file starts a simulation immediately.

Step 1 — Run it as provided

From the repository root:

julia --project -e 'include("examples/3D_run_lenardbalescu_demo_torus.jl")'

This executes the function call at the bottom of the script (currently a long run with ntot=500).

Step 2 — Understand the flow inside the function

run_lenardbalescu_demo_3d_torus_nonradial does the following:

  1. Creates RNG and parameters (rng = MersenneTwister(seed), par = SetParam()).
  2. Sets 3D discretization/time controls (par.dim, par.Nv, par.Npc, par.dt, par.ntot, par.T).
  3. Sets Lenard–Balescu k-space controls (k_perp_order, k_perp_max, k_parallel_width, k_parallel_order).
  4. Sets basis choice (par.spline_order = 0) and Gaussian support (par.gaussian_cutoff_sigma).
  5. Creates output directories and animation objects.
  6. Defines a per-step callback that:
    • samples particles for plotting,
    • builds static and rotating 3D scatter frames,
    • optionally builds a 3×3 combined diagnostics panel.
  7. Calls run_simulation(...) with:
    • torus initializer: initialize_particles_torus_3d(...),
    • diagnostics enabled: savecsv=true, trackconserved=true,
    • callback attached for animation/diagnostics.
  8. Writes GIFs and summary plots to the configured output paths.

Step 3 — Run a shorter/faster variant interactively

For quick iteration, call the function yourself with smaller settings:

using LenardBalescu
include("examples/3D_run_lenardbalescu_demo_torus.jl")

run_lenardbalescu_demo_3d_torus_nonradial(
	 ntot=40,
	 seed=1,
	 batchsize=300,
	 make_animation=false,
	 make_combined_evolution=false,
	 make_plots=true
)

Step 4 — What to modify (and what each knob changes)

Geometry and initialization

  • major_radius: moves torus ring outward/inward in velocity space.
  • tube_radius: changes torus thickness.
  • Initializer is defined in init_particles=(...) -> initialize_particles_torus_3d(...).

Runtime and cost

  • ntot: number of timesteps (largest runtime lever).
  • batchsize: RBM batching size in run_simulation; lower than N enables random batching and usually speeds up runs.
  • par.Nv, par.Npc: particle count/discretization; increasing either increases cost.

Lenard–Balescu fidelity controls

  • par.k_perp_order, par.k_perp_max, par.k_parallel_width, par.k_parallel_order.
  • Higher quadrature/order is typically more accurate but slower.

Output and visualization

  • make_animation, make_combined_evolution, make_plots toggle output products.
  • max_anim_particles controls plotting subsampling.
  • anim_fps, rotate_turns control animation style.
  • out_dir, out_gif, out_gif_rotating, out_gif_combined control file locations.

Practical notes

  • The script currently auto-runs at the bottom. If you want library-style usage only, remove or comment out that last call and invoke the function manually.
  • Output files are written under examples/output/lenard_balescu_3d_torus_nonradial/ by default.
