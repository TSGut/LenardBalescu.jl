LenardBalescu.BasisKernel — Type
BasisKernel(order::Int, e::Float64)

Basis function descriptor for particle-in-cell (PIC) velocity mesh coupling.

Supports multiple basis function orders:

  • 0: Gaussian kernel
  • 1: Linear B-spline
  • 2: Quadratic B-spline
  • 3: Cubic B-spline

Each basis function ψ and its gradient ∇ψ are used to map between particles and the velocity grid.

Arguments

  • order: Kernel order (0=Gaussian, 1=linear, 2=quadratic, 3=cubic)
  • e: Kernel scale parameter (Gaussian width parameter; dilation scale for B-splines)

LenardBalescu.Params — Type
Params

Simulation parameters for Lenard-Balescu or Landau kinetic equation simulations.

Fields

  • gam, beta, c, temp, m: Kernel and physical parameters.
  • Lv, Nv, Npc, N: Velocity grid parameters.
  • T, dt, ntot: Time stepping parameters.
  • batchsize: RBM target batch size (0 disables batching; default full interaction). In RBM mode, particles are repartitioned each step into balanced batches. For 2 <= batchsize < N, this can still reduce cost even when batchsize is close to N (for example, it may produce two roughly equal batches and reduce pair work from about N^2 to about N^2/2).
  • spline_order, use_cell_list: Spline and collision parameters.
  • epsi, cell_h: Derived parameters (set by update_kernel_params!).

LenardBalescu.Collision — Function
Collision(vstack, par, wg, elapsed_s=nothing;
          Vgrid=nothing, use_lenard_balescu=true, verbose=0,
          radial_symmetry=true,
          dielectric_r0, dielectric_dr,
          dielectric_inv_dr, dielectric_len)

Lenard-Balescu (or Landau) collision operator for particle velocities.

Arguments

  • vstack: N×dim particle velocities (dim = par.dim, supports 2 or 3)
  • par: Simulation parameters
  • wg: Particle weights
  • elapsed_s: (optional) Ref for computation time
  • Vgrid: (optional) velocity grid used for reconstruction/precomputation
  • use_lenard_balescu: Use Lenard-Balescu (true) or Landau (false)
  • verbose: Verbosity level
  • radial_symmetry: Controls dielectric preprocessing mode for Lenard-Balescu
  • dielectric_r0: Precomputed interpolation-grid origin (first grid value)
  • dielectric_dr: Precomputed interpolation-grid spacing
  • dielectric_inv_dr: Precomputed inverse spacing (1/dr) for fast indexing
  • dielectric_len: Precomputed interpolation-grid length

Returns

  • N×dim matrix of collision derivatives (dv/dt)

Notes

  • Landau path supports dim = 2 and dim = 3.
  • Lenard-Balescu path supports dim = 2 and dim = 3 in both radial (radial_symmetry=true) and generic (radial_symmetry=false) modes.

Compute the radial integral G(x) for the computed Hilbert transform.

For radially symmetric distributions: G(x) = S{d-2} ∫{|x|}^{∞} f'(r) (r² - x²)^{(d-3)/2} dr

  • dim: Dimension (2 or 3)

LenardBalescu.initialize_particles_stratified_maxwellian — Function
initialize_particles_stratified_maxwellian(N, dV, Vgrid, par, rng)

Stratified initialization of N particles from a Maxwellian distribution on a 2D or 3D velocity grid.

This method distributes particles uniformly across grid cells according to local Maxwellian weights. It produces better coverage than random sampling for low-N simulations, but particles do not form a true random sample. Expect a brief relaxation transient (typically < few collision times) as the ensemble evolves toward a true Maxwellian. For transient-free equilibrium initialization, use initialize_particles_maxwellian instead.

Arguments

  • N: Total number of particles
  • dV: Grid cell width
  • Vgrid: matrix of velocity-grid cell centres (one centre per row), from build_velocity_grid
  • par: Simulation parameters (must contain temp, dim, Lv)
  • rng: (optional) random number generator

Returns

  • (vstack, wg) where vstack is N×2 or N×3 matrix (2D or 3D) and wg is weights

LenardBalescu.precompute_dielectric_data — Function
precompute_dielectric_data(r, f_prime, dim=2, nang=16;
                           radial_symmetry=true, f=nothing, grid=nothing,
                           rho_points_3d=0, psi_points_3d=0)

Precompute G(x) and H[G](x) for efficient dielectric response calculation.

Computes once:

  • G(x) = S{d-2} ∫{|x|}^{∞} f'(r) (r²-x²)^{(d-3)/2} dr
  • H[G](x) = Hilbert transform of G
  • I = ∫_0^∞ f'(r) r^{d-2} dr

Arguments

  • r: Radial grid for distribution (radial_symmetry=true path; otherwise nothing)
  • f_prime: Distribution derivative on radial grid (radial_symmetry=true path; otherwise nothing)
  • dim: Dimension (2 or 3)
  • nang: Angular sampling count for generic (non-radial) mode
  • radial_symmetry: Select radial (true) or generic (false) dielectric preprocessing
  • f: Reconstructed distribution on velocity grid (required in generic mode)
  • grid: Velocity-grid coordinate tuple used in generic mode ((Vx, Vy) or (Vx, Vy, Vz))
  • rho_points_3d, psi_points_3d: Optional 3D non-radial quadrature resolutions

Returns

  • G: G values on extended grid
  • HG: Hilbert[G] values on extended grid
  • r_ext: Extended radial grid [-L, ..., L]
  • I_integral: Normalization integral used in radial mode
